Stad To Do  




**Stad To Do** é projeto desenvolvido no âmbito da unidade curricular  Tecnologias e Sistemas de Informação para Web (TSIW) – 2º Semestre (2025/2026) da ESMAD – P.PORTO.
Tínhamos o objetivo de criar um site que pudesse auxiliar pessoas com TDAH e pessoas com problema de organização de uma maneira gamificada.


---


## Sobre o Projeto


 A crescente necessidade de ferramentas de produtividade que não sejam apenas funcionais, mas sim neurodivergentes por design. Ao contrário dos gestores de tarefas convencionais, esta solução foca-se na clareza visual, na estruturação de rotinas e na gamificação.


## Objetivos


* Disponibilizar diferentes formas de o utilizador se organizar
* Deixar o utilizador engajado nas suas tarefas com o pomodoro e a gamificação
* Oferecer uma extensão browser de forma a sempre conseguir acompanhar as suas tarefas


## Funcionalidades Principais


### **Homepage**
- Cartões responsivos com navegação para as secções principais  
- Layout otimizado para desktop e mobile  
- Destaques visuais e animações suaves  


### **Gestão de Tarefas**
- Criar, editar e remover tarefas  
- Filtros por prioridade, e data  
- Ligação à API para persistência de dados  


### **Pomodoro Integrado**
- Temporizador funcional  
- Ligação à API para registar sessões  
- Feedback visual e sonoro  


### **Diário**
- Criar e escrever pensamentos
- Organizado por dia
- Ligação a API para persistência de dados


### **Sistema de Cidade**
- Sistema de progressão por “casas”  
- Modal interativo  


### **Acessibilidade**
- Modo TDAH
- Modo Escuro
- Mudar o tamanho da letra
- Mudar o volume dos efeitos sonoros
- Todas as configurações salvas no LocalStorage
